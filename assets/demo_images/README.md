# Demo Images

This folder contains two sample images used by the demo inference script:

- `web_019.jpg`
- `synth_00097.jpg`

Run from repository root:

```bash
python scripts/inference.py
```

## Notes

- These images are intentionally small and are kept in the repository so the demo can run directly from GitHub.
- The same demo images are also included in the **Demo ZIP package** (so you can run the demo without cloning the full repository).
- The full dataset used for training/evaluation is hosted externally (see the main repository README).
